# RAG 파이프라인 개선: Vertex AI Reranker 도입

## 변경 전 아키텍처

```
사용자 질문
     │
     ▼
[OpenAI Embeddings]
text-embedding-3-small로 질문 벡터화
     │
     ▼
[Chroma 코사인 검색]
top_k=5 청크 반환
(코사인 유사도 기준 — 의미적으로 비슷한 순)
     │
     ▼
[Gemini 2.5 Flash]
5개 청크를 그대로 컨텍스트로 사용해 답변 생성
```

## 변경 후 아키텍처

```
사용자 질문
     │
     ▼
[OpenAI Embeddings]
text-embedding-3-small로 질문 벡터화
     │
     ▼
[Chroma 코사인 검색]
top_k × 3 = 15개 후보 청크 반환
(더 넓게 수집)
     │
     ▼
[Vertex AI Ranking API]        ← NEW
semantic-ranker-default@latest
질문과 각 청크를 1:1 정밀 비교
15개 → 상위 5개로 압축 + rerank_score 부여
     │
     ▼
[Gemini 2.5 Flash]
정밀하게 선별된 5개 청크로 답변 생성
```

## 설정값

```ini
# rag/.env
RERANKER_ENABLED=true
GOOGLE_CLOUD_PROJECT=project-b54c621b-21b4-427e-95d
RERANKER_MODEL=semantic-ranker-default@latest
RERANKER_TOP_N=5          # 최종 LLM에 넘길 청크 수
RERANKER_FETCH_MULTIPLIER=3  # Chroma에서 top_n × 3 수집
```

비활성화: `RERANKER_ENABLED=false` → 기존 벡터 검색만 사용.
